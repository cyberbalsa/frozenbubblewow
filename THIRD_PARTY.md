# Frozen Bubble upstream

This addon is a GPL-2.0-only adaptation of Frozen Bubble, with a new native Lua engine and WoW interface. It is not affiliated with Blizzard Entertainment.

Original project: https://github.com/kthakore/frozen-bubble

Pinned source commit: `d6a029110ad6ab9e4960052e175addc98807fb7e`.

Imported files: `share/data/levels`; `share/gfx/balls/bubble-{1..8}.gif`; `share/gfx/back_one_player.png`; `share/gfx/shooter.png`; and the selected Ogg tracks listed in `tools/import_upstream.py`. Textures are converted to uncompressed 32-bit TGA; the background is resized. The animation importer compiles the original Catmull–Rom rotation function from `lib/Games/FrozenBubble/CStuff.xs` to generate 201 cannon frames from `share/gfx/shooter.png`. Low graphics uses `share/gfx/shooter-lowgfx.png`. The campaign color indices are shifted from 0–7 to 1–8. The conversion script reproduces these changes.

The project logo is an AI-assisted derivative created using the built-in image generation tool with the upstream artwork as a reference. Its generation prompt is in `art/PROMPT.md`; it is distributed under the same GPL-2.0-only license as this port.

The menu, blink overlays, selection textures, pause frames, compressor, and both penguins' animation sheets are generated by `tools/import_animations.py` from that same checkout. The Lua animation player follows the action, turn, wait, victory, and defeat frame ranges in the original executable. No Peggle assets are included.

The in-game score plaques use lettering rasterized by Frozen Bubble’s SDLPango renderer with DejaVu Sans Book. Multiplayer names use the original 14-point and 8-point contexts, with glyph advances and pair kerning measured by SDLPango. The font notice is in `FrozenBubble/COPYING.hud-font`. To regenerate the lettering on Debian Bookworm with `frozen-bubble` and `fonts-dejavu-core` installed, run `perl tools/import_hud.pl` and then `python3 tools/import_transitions.py /path/to/frozen-bubble` for the opening clock and reveal masks.

The multiplayer lobby uses the original `back_netgame.png` and `menu/highlight-server.png` artwork. Its DejaVu Sans Book and Oblique fonts come from Debian Bookworm’s `fonts-dejavu-core` and `fonts-dejavu-extra` packages (2.37-6). The highscore screens use the Book and Bold faces from the same release. All three are distributed with the notice in `FrozenBubble/COPYING.hud-font`.

Run `python3 tools/import_editor.py /path/to/frozen-bubble` to regenerate the editor artwork. It uses the wooden signs in `level_editor.png`, lettering from `font.png`, the browser controls and the help card. Sign positions and brush hit areas follow `lib/Games/FrozenBubble/LevelEditor.pm`.

The gameplay reference is `bin/frozen-bubble` in the pinned checkout. Run `perl tools/reference_shots.pl /path/to/frozen-bubble` to regenerate the shot fixtures. The generator uses the original Perl collision and grid routines. The Lua tests compare the tick and final board cell for each shot.

The main menu and both board backgrounds, menu logo, and wooden button use the original PNGs at double resolution. After importing the original art, run `python3 tools/upscale_textures.py /path/to/frozen-bubble --binary /path/to/upscayl-bin --models /path/to/models`. This pass uses the digital-art-4x model from [Upscayl 2.15.0](https://github.com/upscayl/upscayl/tree/v2.15.0/resources), with 30% of the original filtered color blended back in for grain. The source alpha sets the silhouette.

[Compare the original and upscaled textures](art/upscayl-comparison.png).

The eight colored bubbles retain their original GIF interiors. The importer renders each on a 128×128 texture, using nearby sprite colors and fractional transparency around the circumference. [Bubble edge comparison](art/bubble-rims.png).

The highscore background, frame, headings and menu credit strips come from the pinned checkout. The 100 level thumbnails use the four-by-four pixel average in `CStuff.xs::shrink_`, with separate sheets for the standard and colorblind sprites.

The campaign regression uses the pinned desktop executable with SDL’s dummy drivers. It checks 84,570 simulation frames across all 100 boards, including wall rebounds, ammunition, falling clusters, ceiling advances, frozen cells and sounds. Regenerate the per-level checksums in an environment with the desktop dependencies using `perl tools/demos/reference_campaign.pl /path/to/frozen-bubble > tests/reference_campaign.lua`.

The live arena uses the original multiplayer backdrop, miniature bubbles and penguin animations, targeting marks, chat panels, and result badges. The miniature cannon uses the same rotation routine with the original 50-pixel shooter.

## Title-screen recordings

The four recordings come from `share/data/demo{1..4}.bz2` in the pinned checkout. Each runs through the original Perl engine. The addon replays the resulting sprite changes and sound cues at 50 frames per second. Board sprites stay separate so the colorblind setting also works on recorded games. The closing wipe follows `blacken_` in `CStuff.xs`.

To regenerate the data, install the desktop game's Perl and SDL dependencies in a disposable Linux environment. The captures used Debian's `frozen-bubble` 2.212 package for the SDL bindings and XS extension. From the addon repository, with `upstream` pointing to the pinned checkout and `traces` to a scratch directory, run the following.

```sh
for n in 1 2 3 4; do
    PERL_HASH_SEED=0 PERL_PERTURB_KEYS=0 perl tools/demos/capture.pl "$upstream" "$traces/trace$n" "$n" || exit 1
done
python3 tools/demos/pack.py "$upstream" "$traces"
```

The uncompressed `tests/demo1.record` is the original training recording. Its regression test runs the WoW engine from the recorded seed and held keys. The reference covers the board, ammunition, airborne projectile and sound cues at every tick. To regenerate it from the SDL capture, run `python3 tools/demos/reference_training.py "$traces/trace1/frames.jsonl" > tests/reference_training.lua`.

The desktop engine iterates Perl hash keys when ejecting a group. Individual pop trajectories can vary between captures of the same recording.

An optional `--reference` argument to the capture command writes desktop screenshots at frames 1, 500 and 950. Use a separate output directory for these.

## Board transitions

Run `python3 tools/import_transitions.py /path/to/frozen-bubble` to regenerate the masks. The importer compiles the five effect routines from the pinned `CStuff.xs`. An offline frame sink records the first step that draws each pixel. The circular, plasma, noise, and brightness patterns retain the original 640×480 grid. Constant rows and columns in the geometric patterns are stored once. The importer also generates brightness masks for individual pieces of board artwork so custom layouts and colorblind bubbles can use the same reveal.

The nine title-logo effects follow the menu loop and pixel transforms in the pinned desktop source. Run `python3 tools/import_title_logo.py /path/to/frozen-bubble` to regenerate the native logo, lettering mask, spotlight patches, television noise, and snowflake. The WoW renderer interpolates the desktop displacement equations across textured quads. The sparkle particles and snow collisions run in Lua.

The full-window pause scene uses `share/gfx/back_paused.png` and `pause_0001.png` through `pause_0035.png`. The animation timing, placement, and repeat point come from the pause loop in `bin/frozen-bubble`. All three music tracks and all seventeen effects called by desktop `play_sound` are the original Ogg files.

The lower-volume effects in `FrozenBubble/Media/Effects` come from the full-volume Ogg Vorbis files in `FrozenBubble/Media`. Run `python3 tools/import_sound_levels.py` with FFmpeg and ffprobe to regenerate them. The generator preserves each clip’s channel count, sample rate and end granule.
