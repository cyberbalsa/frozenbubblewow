# Frozen Bubble upstream

This addon is a GPL-2.0-only adaptation of Frozen Bubble, with a new native Lua engine and WoW interface. It is not affiliated with Blizzard Entertainment.

Original project: https://github.com/kthakore/frozen-bubble

Pinned source commit: `d6a029110ad6ab9e4960052e175addc98807fb7e`.

Copyright © 2000–2012 The Frozen-Bubble Team. The full upstream license and author list are included in `FrozenBubble/COPYING` and `FrozenBubble/AUTHORS.upstream`.

- Design and programming: Guillaume Cottenceau.
- Artwork: Alexis Younes and Amaury Amblard-Ladurantie.
- Soundtrack: Matthias Le Bidan.
- Original level editor: Kim and David Joham.
- Additional network programming: Mark Glines.

Imported files: `share/data/levels`; `share/gfx/balls/bubble-{1..8}.gif`; `share/gfx/back_one_player.png`; `share/gfx/shooter.png`; and the selected Ogg tracks listed in `tools/import_upstream.py`. Textures are converted to uncompressed 32-bit TGA; the background is resized and the shooter padded to power-of-two dimensions. The campaign color indices are shifted from 0–7 to 1–8. The conversion script reproduces these changes.

The project logo is an AI-assisted derivative created using the built-in image generation tool with the upstream artwork as a reference. Its generation prompt is in `art/PROMPT.md`; it is distributed under the same GPL-2.0-only license as this port.

The menu, blink overlays, selection textures, pause frames, compressor, and both penguins' animation sheets are generated by `tools/import_animations.py` from that same checkout. The Lua animation player follows the action, turn, wait, victory, and defeat frame ranges in the original executable. No Peggle assets are included.

The gameplay reference is `bin/frozen-bubble` in the pinned checkout. Run `perl tools/reference_shots.pl /path/to/frozen-bubble` to regenerate the shot fixtures. The generator uses the original Perl collision and grid routines. The Lua tests compare the tick and final board cell for each shot.

The main menu and both board backgrounds, menu logo, and wooden button use the original PNGs at double resolution. After importing the original art, run `python3 tools/upscale_textures.py /path/to/frozen-bubble --binary /path/to/upscayl-bin --models /path/to/models`. This pass uses the digital-art-4x model from [Upscayl 2.15.0](https://github.com/upscayl/upscayl/tree/v2.15.0/resources), with 30% of the original filtered color blended back in for grain. The source alpha sets the silhouette.

[Compare the original and upscaled textures](art/upscayl-comparison.png).

The eight colored bubbles retain their original GIF interiors. The importer renders each on a 128×128 texture, using nearby sprite colors and fractional transparency around the circumference. [Bubble edge comparison](art/bubble-rims.png).
